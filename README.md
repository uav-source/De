# Degen-LIO Day 1-14 Mini Validation

This repository is the minimum executable validation workspace for the first
14 days of Degen-LIO.

The only Day 1-14 scientific question is:

> Can ODI and weak direction explain directional degeneracy in tunnel-like
> LiDAR-Inertial odometry?

Day 1 freezes the problem, formula contract, metric contract, and Day 14
Go/No-Go acceptance criteria. Later days must add executable code, tests,
logs, tables, and figures without changing these contracts unless the report
explicitly records a No-Go reason.
