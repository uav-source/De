# Zero-Perturbation Phase A Minimal Standalone Harness

This repository executes the frozen 210-snapshot, 420-trial Phase A matrix without importing or reading runtime code or snapshots from the source Degen-LIO repository.

The frozen scientific protocol, plans, result schema, backend parameters, metrics, thresholds, copied backend adapters, and PCL CLI are SHA-256 bound by `frozen_assets/frozen_experiment_manifest.json`.

Formal backends are Open3D point-to-plane and PCL point-to-plane. Native registration is forbidden. Phase B execution, Development, Confirmatory, real-data, and paper-mainline authorization remain outside this harness.
